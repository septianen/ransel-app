# Ilustrasi

Maskot IRIS: kapibara petualang bergaya 3D lembut (bulu oranye kecokelatan, perlengkapan hijau zaitun dan cokelat kulit). Semua file PNG transparan 1024 × 1024 px, objek di tengah dengan ruang kosong sekitar 4% di tiap sisi, jadi aman dipakai di `surface` terang maupun gelap.

Pakai ilustrasi untuk state satu layar penuh atau empty state di dalam layar: tampilkan 160–220 dp di tengah, di atas judul `headline` dan deskripsi `body-large` `on-surface-variant`, lalu satu tombol primary. Jangan dipakai sebagai dekorasi di layar yang sudah berisi konten, dan jangan diberi latar, bingkai, atau bayangan tambahan. Satu layar, satu ilustrasi.

Nama file mengikuti pose, bukan layar, supaya bisa dipakai lintas proyek. Kolom "Cocok untuk" adalah saran.

## Catatan

- Latar dibuang otomatis dari gambar asli berlatar putih. Bayangan lantai dijadikan hitam semi-transparan; di beberapa file masih ada sedikit tepi terang di bulu. Kalau tersedia, ganti dengan ekspor transparan langsung dari sumbernya dengan nama file yang sama.
- `capybara-climbing-tree.png`: batang pohon dan batu terpotong lurus di sisi kiri karena gambar sumbernya terpotong. Letakkan menempel ke tepi kiri atau pakai ukuran kecil.
- Beberapa file masih membawa tanda bintang kecil dari generator gambar di pojok kanan bawah (`capybara-dreaming`, `capybara-sleeping-backpack-cocoon`, `capybara-tired-phone`, `capybara-lounging-lantern`, `capybara-sleeping-nightcap`, `capybara-taking-photo-side`, `capybara-eating-bento`). Sebaiknya diekspor ulang tanpa tanda itu dari sumbernya.
- `capybara-tablet.png` dan `capybara-napping-blanket.png` memperlihatkan logo merek di bagian belakang ponsel. Hindari untuk rilis publik atau minta versi ponsel tanpa logo.
- Untuk aplikasi, ekspor ulang ke WebP 2× ukuran tampil (mis. 440 px untuk 220 dp) supaya ringan.
- Teks alternatif: ilustrasi bersifat dekoratif (`alt=""`, `contentDescription = null`) karena judul di bawahnya sudah menjelaskan state.
